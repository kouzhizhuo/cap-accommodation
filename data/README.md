# data/

- stimuli/: variety-twin requests and renderings (ours, CC BY 4.0) and the rule/lexicon files used to render them.
- stimuli/armN/: WildChat-1M items as identifiers and source hashes only (text removed); rebuild with the mining script against the original release.
- Third-party corpora (human-written AAE tweets with translations, EnDive) are not included; see the README for rebuild scripts.
